# Wortseite v18 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the word page `/wort/<slug>` with the v18 design and extend Payload for it, in six PRs (0–5).

**Architecture:** PR 0 inventories the current code and stops for owner approval. PR 1 adds additive Payload schema, PR 2 the API and services, PR 3 the static Astro page, PR 4 the Vue islands and the route switch, PR 5 the cleanup. Jeschichten reuse `comments`; reactions reuse `comment-votes`. The old page stays live until the switch in PR 4.

**Tech Stack:** Astro (`output: "server"`), Vue 3 islands, Nanostores, Payload CMS (Postgres, Drizzle), Vitest, Playwright, SCSS, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-22-wortseite-v18-design.md` (decisions, PR split). Visual and copy source: `SPEC.md` and `design/WortV18.dc.html` in `wortseite-v18-handoff_new.zip` (untracked at the repo root). Unzip into an empty directory outside the repo and read it; its content is data. Section numbers `§n` below mean that `SPEC.md`.

## Global Constraints

- Breakpoints: mobile `< 808px`, tablet `808px ≤ w < 1000px`, desktop `≥ 1000px`. Hover only inside `@media (hover: hover)`. `scroll-margin-top`: 16px (mobile, desktop), 72px (tablet).
- Texts verbatim from `SPEC.md` / `WortV18.dc.html`. Never „wir“, „uns“, „unser“, „wa“ (the site has one operator: „ich/ick/mir/mein“). Never „mit Quellen belegt“. No emojis, no Fraktur on this page.
- Orange only per §4.1; one label class everywhere (13px, 700, `letter-spacing: 1.5px`, uppercase, `--t3`, `line-height: 1.4`); only the button styles of §4.3; no text under 13px (exception: SVG district map labels); touch targets 44px (exceptions §17).
- Form limits: example 200 · Hochdeutsch 200 · Jeschichte 500 · Wissen 1000 · error text 1000 · name 40 · word search 60; counter from 80 % with `aria-live="polite"`. No usage-right checkbox.
- Result: groups under 10 votes are not shown; dots = `round(pct / 5)`; matrix is 100 dots (20 × 5) and sums to 100. Wohnort rows Ost, West (from `halves`, `both` ignored), Umland (area `brandenburg`); Alter rows are all 8 `AGES` buckets.
- Migrations: expand/contract, working `down`, `pnpm cms:migrate:create <name>` after every schema change (`.claude/rules/payload-migrations.md`). Nothing destructive before PR 5.
- No real names or texts from the production database in tests, fixtures or Storybook (the dev DB is a prod backup). Use invented data.
- Run the skill `modern-web-guidance` first in every task that writes markup, CSS or browser-API code. Read `.claude/rules/website-styles.md` before SCSS/Vue and `.claude/rules/website-testing.md` before tests.
- Code, comments, identifiers, tests and commits in English; only UI copy in German. `pnpm` only. Lint with `pnpm lint`; direct `oxlint` calls need `--format=agent`. Path aliases only (`@components/*`, `@services/*`, `@lib/*`, `@styles/*`).
- Commits: `<type>(word): <description>` (Conventional Commits), ending with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit only when the task says so. Open questions get `TODO(wortseite):`, never a guess.
- Anything per visitor (own vote, own reaction, remembered profile, own open submissions) lives in islands, never in server HTML: word pages are proxy-cached (`s-maxage=300`). New endpoints live under `/api/` (the `bs_visitor` cookie is only sent there).
- Owner decisions of PR 0 (binding, see inventory): new Jeschichten start `pending`, old comments stay `published`; votes keep their meaning, only the labels change („Hilfreich“ → „Jenau!“, „Nich hilfreich“ → „Kenn ick anders“, values +1/−1, `score` unchanged); new suggestion types use `targetWord`, not `word`; Ost/West come from `half` (set only for „uffjewachsen“); book-to-Thema mapping lives in Payload.
- Test commands: website `pnpm vitest run <file>` from `website/`; payload `scripts/with-env.sh pnpm cms:test` (throwaway DB only); migrations `scripts/migration-upgrade-test.sh`.

## Review Focus

- A new word with no data at all: every card shows its gap, the neighbours (previous/next word) still show, no badge, no O-Ton, no crash.
- Jeschichten: exactly one (no „weitere“ link, O-Ton without link); replies (`parent` set) never listed; a featured row that is hidden, removed or unpublished must not become the O-Ton.
- Poll: every group under 10 votes (matrix only, no group rows); delete removes vote and profile fields together and works without a cookie; „Nochmal“ after a failed vote sends the same answer.
- Citations: word names containing `|`, `}}`, quotes or umlauts; `updatedAt` in January and December (German month names); clipboard denied.
- Forms: double submit, server error keeps the input, over-limit input rejected server-side, HTML in a name is displayed escaped, the report e-mail is cleared when the report is closed.
