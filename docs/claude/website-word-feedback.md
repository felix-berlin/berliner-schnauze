# Word feedback (website)

Moved verbatim from `website/CLAUDE.md`. Read before changing the poll, `/api/word-feedback` or the `word-feedback` collection.

- **Word feedback**: the poll island `word/WordPoll.vue` (states vote, questions, result; result maths in `lib/pollResult.ts`; Like/Dislike sit in `WordActions` and go through `composable/useWordReaction.ts` and the same shared `$feedback` store). The poll starts straight away: after the vote the result and the first question follow at once, `← Zurück` leads to the vote, a polite live region (`role="status"`) says "Danke, deine Stimme is drin!" → `/api/word-feedback` (GET/PATCH/DELETE) → Payload `word-feedback`, one row per visitor and word (`visitor` = sha256 of cookie AND word, so rows of one person share no value; rows with the old cross-word hash are found and moved on the next write; DELETE removes all rows of the cookie by recomputing the hash for every word), every answer optional (usage, like/dislike, area, locality, origin, east/west, age bracket; spec: `docs/superpowers/specs/2026-11-02-word-feedback-design.md`). Client state in `src/stores/wordFeedback.ts`: the profile lives in memory and goes to localStorage (`bs-word-feedback-profile`) only after the visitor ticks "Meine Angaben für weitere Wörter merken" (`$remember`, `bs-word-feedback-remember`). The profile answers are not sent to Matomo. The retention job removes `visitor` after 13 months. Identity is a visitor cookie like `comment-votes`; no IPs are stored (the per-IP write cap lives in memory only). Counts are never stored on `words`: they are computed live from `word-feedback` and reach the CMS admin through the `ui` field `feedbackCounts` (`payload/src/collections/Words.ts`); the public page has no sidebar. Comparison groups show only with >= `MIN_GROUP` (10) votes. The map shows the 12 current Bezirke as `area` keys (+ `brandenburg`, `elsewhere`); an optional step "Welcher Kiez?" then asks the `locality` (Ortsteil) from a button list for that area, no locality map. Area/locality keys, the 97 localities (de.wikipedia "Verwaltungsgliederung Berlins") and the locality→area mapping live once in `payload/src/lib/wordFeedback.ts` (`payload-app/word-feedback`); the API only accepts a locality together with its own area and clears it when the area changes. Map data: `scripts/berlin-map/build.py` (Bezirke GeoJSON only) → `src/data/berlinAreas.ts` (licence note in its header). Visitors delete their rows with "Stimme und Angaben löschen" in the card, which asks "Wirklich löschen?" in a local inline `role="alertdialog"` of `WordPoll.vue` (not `ConfirmDialog`).
