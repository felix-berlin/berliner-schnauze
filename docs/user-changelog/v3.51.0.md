Diesmal vor allem ein Fix, der für Betroffene ziemlich ärgerlich war: Wer ein Wort vorschlagen wollte, kam teils gar nicht durch.

---

## Wort-Vorschläge kommen jetzt an

Das Formular zum Einreichen neuer Wörter hatte zwei Bugs, die sich gegenseitig verdeckt haben. Zum einen wurden eingereichte Vorschläge von E-Mail-Anbietern teils als Spam aussortiert, weil die Absenderadresse falsch gesetzt war. Zum anderen brach das Formular in manchen Fällen mit einem Fehler ab, bevor die Anfrage überhaupt rausging. Beides ist behoben, Vorschläge kommen jetzt zuverlässig bei mir an.

---

## Verbesserungen im Hintergrund

- Die Suche nach ähnlich klingenden und ähnlich geschriebenen Wörtern läuft jetzt mit Zwischenspeicherung, was unnötige Wiederholungsarbeit spart
- Das Laden von Magazin-Artikeln wurde vereinheitlicht
- Das Wort des Tages wird nicht mehr versehentlich beim Bauen einer neuen Version abgefragt
