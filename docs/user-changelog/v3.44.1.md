## Statistik im Footer repariert

Im Footer zeigt Berliner Schnauze an, wie viele Stunden ich schon an dem Projekt programmiert habe. Die Datenquelle dahinter ist zuletzt regelmäßig in einen Timeout gelaufen, wodurch die Zahl manchmal einfach gefehlt hat. Ich bin auf einen Endpunkt mit zwischengespeicherten Daten umgestiegen, seitdem taucht die Statistik wieder zuverlässig auf.
