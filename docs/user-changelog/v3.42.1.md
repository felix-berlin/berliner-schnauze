## Firefox ESR erkannt

Die Browser-Erkennung hat Firefox ESR bisher nicht als unterstützt eingestuft, obwohl die Seite damit eigentlich problemlos funktioniert. Wer diese Firefox-Variante nutzt, zum Beispiel über firmenweit verwaltete Rechner, bekam dadurch unnötig einen Hinweis auf einen veralteten Browser angezeigt. Das ist jetzt behoben.
