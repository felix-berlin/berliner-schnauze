# Test words

The invented data set of `pnpm --filter payload-app seed:e2e` (`payload/src/seed/e2e.ts`): the only test words there are.
It runs on a throwaway database (name ends in `_e2e`), never on the worktree's real one; the real words of the dev
database are production data and stay untouched. How to start it for a manual check: `website/CLAUDE.md`, section E2E.

**To see every card of the word page with data, open `/wort/abjang`.** A second look at the same page without data is
`/wort/wa` or `/wort/ab`.

The seed holds exactly 28 words: the word of the day on the pinned e2e day is `abjang` only for a count of 28 or 34, so
add a word only by dropping one. `abjang` must also stay at sorted index 4 (the day number modulo 28), so a new filler word
must not sort before "abjang". `payload/tests/seed.test.ts` fails when this table and the seed drift apart.
